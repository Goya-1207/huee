# 沪屙屙 · 上海地铁找厕所

一个面向上海地铁出行场景的厕所查询与路线推荐小程序。项目会结合当前位置、目的地、可等待时间、厕所所在付费区和换乘线路，为用户推荐更顺路的厕所。

仓库同时保留：

- 微信小程序原生实现：`miniprogram/`
- 浏览器静态原型：`沪屙屙.html`、`沪屙屙-真机版.html`

## 当前功能

- 415 个唯一地铁站、19 条线路、502 个厕所点位。
- 根据真实定位扫描附近车站，并支持多个邻近站点手动选择。
- 按线路、站名、热门、附近和收藏选择始发站及终点站。
- 地铁图站点详情展示本站全部厕所，可在半屏卡片内滚动。
- 厕所详情区分线路、站台/站厅、付费区、出入口、步行时间和无障碍设施。
- 收藏站点、常用线路、性别、如厕需求及时间偏好本地保存。
- 支持反馈记录和微信小程序登录资料同步入口。
- 使用 `requiredComponents` 开启组件按需注入。

## 综合线路与厕所推荐

路线规划首先考虑总时长和换乘次数：

```text
线路综合成本 = 预计乘车时间 + 换乘次数 × 10 + 连续短距离换乘惩罚
```

系统最多生成 3 个合理方案，包括综合推荐、较快方案和少换乘/不同换乘点方案，并过滤明显绕远或换乘过多的路线。

每个线路方案会独立计算厕所推荐，主要考虑：

- 到达厕所的总时间和用户可等待时间。
- 厕所是否位于本次实际乘坐或换乘的线路。
- 换乘后的出发线路站台厕所是否可以解决后直接候车。
- 付费区、非付费区、站外及是否需要出闸。
- 站台、站厅、出口方向和车头/车尾位置。
- 男厕、女厕和无障碍需求。
- 同站多个厕所的实际绕行成本。

当换乘次数相同、总时长接近且线路组合一致时，如果最后一段需要长距离乘坐，算法会优先更早进入该线路，提高获得座位的可能性。

示例：锦绣路到嘉定北当前推荐：

```text
7号线 → 14号线 → 11号线
静安寺换乘14号线，曹杨路换乘11号线
换乘2次，全程约82分钟
厕所：静安寺14号线站台，往B方向车尾
```

## 厕所数据

厕所数据以[上海地铁官方车站信息](https://service.shmetro.com/czxx/index.htm)为主要基线，并结合上海市政府、市交通委和申通地铁公开公告核对新增、迁移及改造点位。当前数据核验日期为 **2026-09-20**。

本轮已覆盖：

- 2号线蟠祥路·国家会计学院站。
- 17号线西岑站。
- 18号线二期通南路、长江西路、爱辉路、呼兰路、康文路。
- 人民广场、陆家浜路、自然博物馆、上海西站、南翔等站新增或改造厕所。
- 国家会展中心2/17号线换乘关系及站名更新。

厕所数据源位于 `data_0.jsx`～`data_8.jsx`，不要直接修改生成后的 `data.jsx`。

## 开发与构建

### 微信小程序

使用微信开发者工具打开仓库根目录。工程配置已经指定：

```json
{
  "miniprogramRoot": "miniprogram/"
}
```

定位功能需要：

- `scope.userLocation`
- `requiredPrivateInfos: ["getLocation"]`
- 在微信公众平台申请并说明 `wx.getLocation` 的使用场景

### 浏览器原型

项目无 npm 依赖和打包步骤，使用静态服务器运行：

```bash
python -m http.server 8000
```

然后访问：

- `http://localhost:8000/沪屙屙.html`
- `http://localhost:8000/沪屙屙-真机版.html`

### 数据生成

修改 `data_N.jsx` 后重新生成浏览器数据：

```bash
node scripts/build-data.js
```

同步小程序策略到浏览器原型：

```bash
node scripts/sync-browser-strategy.js
```

重新生成小程序地铁线路与站点坐标：

```bash
node scripts/build-metro-geo.js
```

## 验证

当前核心回归用例：

- 网页端和小程序端数据一致：415 站 / 502 个厕所。
- 锦绣路 → 嘉定北：7 → 14 → 11，静安寺、曹杨路换乘，共2次换乘。
- 静安寺推荐14号线站台厕所，并标注对应线路方案。
- 曹杨路详情展示3处厕所，其中3/4号线共用厕所只计一个实体点位。
- 新增站点可以参与寻路并生成地图标记。
